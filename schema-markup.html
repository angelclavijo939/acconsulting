¿Qué es Schema Markup (JSON-LD)?

Schema Markup es un código estructurado que ayuda a los motores de búsqueda (como Google) a entender mejor el contenido de tu página. Es como darle a Google un "manual de instrucciones" sobre qué información contiene tu sitio.

JSON-LD es el formato recomendado por Google para implementar schema markup. Las siglas significan:

  • JSON: Formato de datos simple y legible
  • LD: Linked Data (datos vinculados/estructurados)
💡 ¿Por qué es importante?
Sin schema markup, Google ve tu contenido como "texto plano". Con schema, entiende que eres una agencia, dónde estás, qué servicios ofreces, cuál es tu experiencia, etc. Esto mejora:
  • 🏆 Rankings en búsqueda orgánica
  • ⭐ Rich snippets (reseñas con estrellas, precios, etc.)
  • 🔍 Knowledge Panels
  • 📱 Resultados en búsqueda visual
  • 🎯 Señales de E-A-T (Experiencia, Autoridad, Confianza)

Tipos de Schema que Necesitas

Schema Type Ubicación Propósito Prioridad
Organization Página principal (/) Información general de la empresa 🔴 CRÍTICA
LocalBusiness Página principal Ubicación, teléfono, horarios 🔴 CRÍTICA
Service Cada página de servicio Descripción de cada servicio 🟠 ALTA
Person Página About Información del fundador (Ángel Clavijo) 🟠 ALTA
BreadcrumbList Todas las páginas Navegación breadcrumb 🟡 MEDIA

1️⃣ Schema Organization (Página Principal)

Este es el schema más importante. Cópialo y pégalo dentro del <head> de tu página principal.

5️⃣ Schema BreadcrumbList (Todas las Páginas)

Aparece como breadcrumbs en resultados de Google. Ejemplo para página de servicio:

📋 /servicios/desarrollo-software.html - Dentro de <head>
{ "@context": "https://schema.org", "@type": "BreadcrumbList", "itemListElement": [ { "@type": "ListItem", "position": 1, "name": "Home", "item": "https://ac-consulting.cloud" }, { "@type": "ListItem", "position": 2, "name": "Servicios", "item": "https://ac-consulting.cloud/servicios" }, { "@type": "ListItem", "position": 3, "name": "Desarrollo de Software", "item": "https://ac-consulting.cloud/servicios/desarrollo-software.html" } ] }

Cómo Implementar en tu Sitio

Paso 1: Obtener el Código

Cada schema JSON-LD anterior tiene un botón "Copiar Código". Cópialo.

Paso 2: Abrir el HTML

Abre el archivo HTML de tu página (ej: index.html).

Paso 3: Pegar en <head>

Busca la sección <head> y pega el código:

<head> <meta charset="UTF-8"> <title>AC-Consulting</title> ... <!-- JSON-LD Schema --> <script type="application/ld+json"> { "@context": "https://schema.org", ...tu código aquí... } </script> </head>

Paso 4: Validar

Usa la herramienta de validación de Google para confirmar que sea correcto.

✓ Implementación Rápida:
Si usas un CMS (WordPress, Webflow, etc.), hay plugins que automatizan esto. Google Structured Data Markup Helper también puede ayudarte.

Herramientas para Validar Schema Markup

1. Schema.org Validator

  • URL: schema.org/validator
  • Qué hace: Valida que tu JSON-LD sea sintácticamente correcto
  • Cómo usar: Pega tu código JSON-LD y click en "Validate"

2. Google Rich Results Test

  • URL: search.google.com/test/rich-results
  • Qué hace: Prueba si Google reconoce correctamente tu schema
  • Cómo usar: Introduce tu URL y click en "Test URL"

3. Google Structured Data Testing Tool (Legacy)

  • URL: Markup Helper
  • Qué hace: Visualiza cómo Google interpreta tu schema

4. JSON-LD Playground

  • URL: json-ld.org/playground
  • Qué hace: Editor en línea para probar JSON-LD
💡 Proceso de Validación Recomendado:
1. Valida la sintaxis en Schema.org Validator
2. Prueba en Rich Results Test
3. Revisa la consola de Chrome (DevTools) para errores
4. Envía tu URL a Google Search Console para indexación

Preguntas Frecuentes

❓ ¿Mejora el SEO inmediatamente?

No de forma inmediata, pero es muy importante. Google necesita rerastrear y reindexar tu sitio (puede tomar 1-4 semanas). El impacto es gradual pero significativo.

❓ ¿Cuántos schemas puedo tener en una página?

Puedes tener múltiples schemas en la misma página (Organization + LocalBusiness + BreadcrumbList). De hecho, es recomendado.

❓ ¿Qué pasa si hay errores en mi schema?

Google los ignora. No te penaliza, simplemente no los usa. Valida siempre antes de publicar.

❓ ¿Necesito actualizar el schema cada vez que cambio algo?

Sí. Si cambias tu teléfono, dirección, servicios, etc., actualiza el schema. Google lee la información de ahí.

❓ ¿Puedo usar script tag o meta tag?

Google prefiere JSON-LD (dentro de <script type="application/ld+json">). Es el estándar moderno.

❓ ¿Rich snippets aparecen automáticamente?

Con schema correcto, tienes más probabilidades. Google decide mostrarlos basado en relevancia y contexto. No es garantía, pero aumenta las chances en 15-30%.
